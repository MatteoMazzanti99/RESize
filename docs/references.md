# References

Every formula and typical value in RESize points to a publication, a standard or a dataset. Open the **Why?** panel of any step to see the sources of that step; the PDF report ends with the references it cites.

Standards and reports are revised: use the current edition when you cite them. Where a choice is RESize's own simplification and has no external source, the panel says so.
